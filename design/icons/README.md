# Icons

Uicons Regular Rounded by [Flaticon](https://www.flaticon.com/uicons), extracted from the `@flaticon/flaticon-uicons` npm package (v3.3.1) with `extract_icons.py`.

License: free with attribution. The app must credit "Uicons by Flaticon" (planned for You > About). A Flaticon Premium subscription removes the attribution requirement.

Regenerate or add icons:

```
npm pack @flaticon/flaticon-uicons && tar xzf flaticon-flaticon-uicons-*.tgz
python3 extract_icons.py package out home,search,bell
```

For Android, import each SVG with Android Studio > New > Vector Asset.
